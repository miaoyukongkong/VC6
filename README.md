├── ch01/               第 1 章
│   ├── ch01.dsw
│   ├── ch01.dsp

## 如何编译运行

1. 双击对应章的 `.dsw` 用 VC6 打开工程；
2. `F7` 编译并链接；
3. `Ctrl+F5` 运行（窗口会停留，便于看输出）。

| 操作 | 快捷键 |
|:--|:--:|
| 只编译当前文件 | `Ctrl+F7` |
| **Build（编译 + 链接整个工程）** | **`F7`** |
| **运行** | **`Ctrl+F5`** |
| 单步调试 | `F10` / `F11` |

> 单独一个 `.cpp` 不能直接运行：`Ctrl+F7` 只生成 `.obj`，`F7` 需要工程（`.dsp`）上下文。

## 一个工程里写多道题

若一个工程里有多个 `.cpp` 且都带 `main()`，链接会报：

```
LINK : fatal error LNK2005: _main already defined
```

本仓库采用「做完的题移出工程」的约定：

```
chNN/
├── chNN.dsw / chNN.dsp
├── main.cpp      ← 当前在做的题（唯一有 main）
└── done/         ← 已完成的题（不加入工程）
```

另外两种处理方式（按需选用）：

- 用 `#if 0 ... #endif` 包住暂时不参与编译的题；
- 在 VC6 的 FileView 中右键文件 → Settings → 勾选 *Exclude file from build*。

## 文件命名规范

文件名一律使用**英文**（VC6 对中文文件名支持很差）。

| 前缀 | 含义 | 示例 |
|:--:|:--|:--|
| `p` | 教材例题 | `p4-1-class-myComplex-operator-overloading.cpp` |
| `c` | 课后习题 | `c3-4.4-object-array.cpp` |

> 归档文件统一放在各章 `done/` 目录下，命名带上小节号或题号，便于回查。

|:--|:--:|:--|

## 常见问题

| 现象 | 处理 |
|:--|:--|
| 中文文件名编译失败 | 文件名改英文 |
| `F5` 运行窗口一闪而过 | 改用 `Ctrl+F5` |
| 工程路径含空格导致报错 | 放在无空格路径下 |
| 移动目录后 `.dsw` 打不开 | 记事本打开 `.dsp`，把绝对路径改为相对路径 |
| `Add Files to Project...` 导致 VC6 闪退 | 用 `File → New → Files → C++ Source File` 新建，勾选 *Add to project*；已有文件可直接手改 `.dsp` |
| 多个 `main()` 链接冲突 | 见「一个工程里写多道题」 |
| `C2871: 'std' : does not exist or is not a namespace` | 头文件里不要写 `using namespace std;` |
| `string::size()` / `substr` 切中文乱码 | VC6 的 `string` 是字节串，一个汉字 = 2 字节，按字节操作要自己步进 |
| `warning C4508: function should return a value` | `main` 末尾补 `return 0;` |

## 代码时代差异（VC6 vs 现代 C++）

| 项 | VC6 / 老教材 | 现代标准 |
|:--|:--|:--|
| 头文件 | `#include <iostream.h>` | `#include <iostream>` + `using namespace std;` |
| `main` | 教材常写 `void main()` | `int main() { ... return 0; }` |
| 预编译头 | 选 "simple application" 会带 `stdafx` | 建 "empty project" 避免 |
| 字符编码 | GBK（中文 2 字节） | UTF-8 / Unicode |

> 代码按教材风格书写，以便与 VC6 环境一致；现代写法另作对照。
