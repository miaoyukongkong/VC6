## 一、单独一个 .cpp 文件，能不能用 VC6 运行？

**答案：能，但不在 IDE 里 —— 要走命令行 `cl.exe`。**

### 1.1 两条路径对比（实测结论）

| 路径 | 能运行单独 .cpp？ | 说明 |
|---|:--:|---|
| **VC6 IDE（msdev.exe）** | 🔴 **不能** | `Ctrl+F7` **只编译成 .obj，不链接、不生成 exe**；`F7` Build 必须有工程（.dsp）上下文 |
| **命令行 cl.exe** | 🟢 **能** | 一条命令即生成 exe 并可直接运行 |

> 🔴🔴 **重要纠正：我最初说"Ctrl+F7 编译 → Ctrl+F5 运行，不需要工程"是错的。**
> **VC6 IDE 里 `Ctrl+F7` 只做单文件编译，不生成 exe；`Ctrl+F5` 需要已存在的 exe。**

### 1.2 推荐做法：用 `cc.ps1` 脚本（已备好）

```powershell
# 在 D:\VC6 目录下
.\cc.ps1 cpp\p01_hello.cpp          # 编译 + 运行
.\cc.ps1 cpp\p01_hello.cpp -Only    # 只编译
```

**脚本自动做的事：**
1. 设置 `PATH` = `VC98\Bin` ＋ `MSDev98\Bin`（**后者提供 MSPDB60.DLL**）
2. 设置 `INCLUDE` / `LIB`
3. 调 `cl /nologo xxx.cpp` → 生成同目录 `xxx.exe`
4. 自动运行并显示输出

**实测输出（VC6 编译器版本 12.00.8804）：**
```
===== 编译 _t.cpp =====
_t.cpp
===== 运行 _t.exe =====
cc.bat works!
===== 结束 =====
```

### 1.3 🔴 三个必须知道的坑（都是实测踩出来的）

| # | 坑 | 现象 | 解法 |
|:--:|---|---|---|
| **1** | **缺 MSPDB60.DLL** | `cl.exe` 报 `exit -1073741515`（0xC0000135 = 找不到 DLL）| 该 DLL 在 `Common\MSDev98\Bin\`，**必须把这个目录也加进 PATH** |
| **2** | **`VCVARS32.BAT` 不可用** | 绿色版里它硬编码旧路径 `D:\PROGRA~1\MICROS~1\VC98`，与实际不符 | 不用它，自己在脚本里设 PATH/INCLUDE/LIB |
| **3** | **路径含中文 `完整绿色版`** | `.bat` 里 `cl` 命令找不到（编码问题）| 🟢 **`.ps1` 不受影响**（本脚本即因此选择 PowerShell）|

> 🟢 **建议（可选）：把 VC6 安装目录移到全英文路径**，如 `D:\VC6Tool\` —— VC6 是 1998 年产品，对中文路径敏感，移走后 `.bat` 也能用。

### 1.4 什么时候才需要建工程（.dsp/.dsw）

| 情况 | 为什么 |
|---|---|
| 多文件（.h + .cpp 分离）| 需要管理文件列表 |
| 断点单步调试 | 需要 Debug 信息 |
| 一个练习含多个源文件 | 需要链接多个 .obj |

**→ 教材例题、课后习题、单个 .cpp 练习：用 `cc.ps1` 就够，不必建工程。**

## 三、文件命名规范（🔴 严格英文）

**VC6 是 1998 年的产品，中文文件名编译会失败。**

| 前缀 | 含义 | 示例 |
|:--:|---|---|
| `p` | program（教材例题）| `p03_pointer_swap.cpp` |
| `e` | exercise（课后习题）| `e03_pointer_swap.cpp` |
| `t` | test（自测）| `t02_bubble.cpp` |
| `w` | wrong（踩坑留档）| `w01_missing_header.cpp` |

**建议带页码/例题号便于回查：** `p_p68_ex3-2.cpp`

## 四、编译产物隔离

| 文件 | 入库？| 原因 |
|---|:--:|---|
| `.cpp` / `.h` | ✅ | 源代码（核心资产）|
| `.dsp` / `.dsw` | ✅ | 工程定义（重建困难）|
| `.ncb` | ❌ | IntelliSense 库，可达几十 MB |
| `.opt` / `.plg` / `.aps` / `.clw` / `.suo` | ❌ | IDE 用户设置 |
| `.obj` / `.exe` / `.ilk` / `.pdb` / `.pch` / `.idb` / `.exp` / `.lib` | ❌ | 编译产物 |
| `Debug/` / `Release/` | ❌ | 输出目录 |

## 六、VC++ 6.0 已知坑（8 条）

| # | 坑 | 应对 |
|:--:|---|---|
| **1** | **中文文件名编译失败** | 文件名严格英文 |
| 2 | 路径含空格报错 | `D:\VC6\` 无空格 ✅ |
| **3** | 中文路径偶发 "cannot open file" | `D:\VC6` 全英文路径 ✅ |
| 4 | 默认不生成 Debug 信息 | 建工程选 `Win32 Console Application` → 空工程 |
