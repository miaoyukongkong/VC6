## 🔴 一、最重要的一条：**教材小代码不要建工程**

| 操作 | 快捷键 | 结果 |
|---|---|:--:|
| 编译单个 .cpp | **Ctrl+F7** | 生成 .obj |
| 链接生成 exe | **F7** | 生成 .exe |
| 运行（窗口停留）| **Ctrl+F5** | 运行并等待按键 |

**→ 教材例题、课后习题、单个 .cpp 练习：一律不建 .dsp/.dsw**

**只有三种情况才建工程：** ① 多文件（.h + .cpp）② 断点单步调试 ③ 一个练习含多个源文件

## 三、文件命名规范（🔴 严格英文）

**VC6 是 1998 年的产品，中文文件名编译会失败。**

| 前缀 | 含义 | 示例 |
|:--:|---|---|
| `p` | program（教材例题）| `p03_pointer_swap.cpp` |
| `e` | exercise（课后习题）| `e03_pointer_swap.cpp` |
| `t` | test（自测）| `t02_bubble.cpp` |
| `w` | wrong（踩坑留档）| `w01_missing_header.cpp` |

**建议带页码/例题号便于回查：** `p_p68_ex3-2.cpp`

## 四、编译产物隔离

| 文件 | 入库？| 原因 |
|---|:--:|---|
| `.cpp` / `.h` | ✅ | 源代码（核心资产）|
| `.dsp` / `.dsw` | ✅ | 工程定义（重建困难）|
| `.ncb` | ❌ | IntelliSense 库，可达几十 MB |
| `.opt` / `.plg` / `.aps` / `.clw` / `.suo` | ❌ | IDE 用户设置 |
| `.obj` / `.exe` / `.ilk` / `.pdb` / `.pch` / `.idb` / `.exp` / `.lib` | ❌ | 编译产物 |
| `Debug/` / `Release/` | ❌ | 输出目录 |

## 五、学习流程

```
1. 读教材 → 建 pXX_xxx.cpp
2. VC6 打开单文件 → Ctrl+F7 编译 → Ctrl+F5 运行
3. 改参数/改逻辑 → 观察变化
4. 有意犯一个错 → 看懂报错（w 前缀留档）
5. 🔴 合上教材，从零重写一遍（不看原代码）
```

> 🔴 **第 5 步是核心** —— 实践课是**上机闭卷**，看着教材敲在考场等于不会。

## 六、VC++ 6.0 已知坑（8 条）

| # | 坑 | 应对 |
|:--:|---|---|
| **1** | **中文文件名编译失败** | 文件名严格英文 |
| 2 | 路径含空格报错 | `D:\VC6\` 无空格 ✅ |
| **3** | 中文路径偶发 "cannot open file" | `D:\VC6` 全英文路径 ✅ |
| 4 | 默认不生成 Debug 信息 | 建工程选 `Win32 Console Application` → 空工程 |
| 5 | `F5` 窗口一闪而过 | 用 **Ctrl+F5**，或 main 末尾加 `system("pause");` |
| 6 | 高版本 Windows 兼容 | 已装好 |
| **7** | **`.dsp` 存绝对路径** | **建工程时选相对路径**，否则移动目录打不开 |
| 8 | 多工程同目录互相干扰 | 每练习一个工程 → 单独子目录 |

## 七、代码时代差异（VC6 vs 现代 C++）

| 项 | VC6/老教材 | 现代标准 |
|---|---|---|
| 头文件 | `#include <iostream.h>` | `#include <iostream>` + `using namespace std;` |
| main | 教材常写 `void main()` | 建议 `int main() { ... return 0; }` |
